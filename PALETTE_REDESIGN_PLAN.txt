================================================================================
  PLANO: REDESIGN DA PALETA DE CORES — ESTÉTICA FINAL FANTASY XIV
================================================================================

CONTEXTO
--------
O projeto é um portal web React + TypeScript + Tailwind CSS v4 para uma Free
Company do FFXIV. A paleta atual usa tons de teal acadêmico (#1D6A6A) e
dourado (#D4AF37) — inspirada no tema "Sharlayan". A paleta é centralizada no
src/index.css via bloco @theme {} (Tailwind v4), com dark mode em
:root[data-theme="dark"]. Existem ~15% de cores hardcoded espalhadas em
componentes.

================================================================================
DIREÇÃO ESTÉTICA FFXIV
================================================================================

Baseado na pesquisa visual do FFXIV (Lodestone, UI themes, paleta do jogo), a
estética FFXIV se caracteriza por:

  Elemento                    Cor FFXIV Típica               Uso no Jogo
  ─────────────────────────────────────────────────────────────────────────────
  Azul Profundo (Hydaelyn)   #1B3A5C ~ #2D4F7E              Fundo de menus
  Dourado Lodestone           #BFA34C ~ #C9A84C              Hiperlinks, bordas
  Azul Cristalino             #4C7EE8 ~ #5B9BD5              Links clicáveis
  Vermelho Combat             #732828 ~ #9B3030              DPS, avisos
  Verde Support               #346624 ~ #4A8B3F              Tanks, cura
  Azul Noite                  #1A1A2E ~ #0F1923              Dark mode bg
  Cinza Nebuloso              #2A2D3A ~ #3A3D4A              Dark mode surfaces
  Branco Gelo                 #E8EDF4 ~ #F0F4FA              Texto dark mode
  Parchment                   #F5F0E1 ~ #EDE6D3              Light mode bg
