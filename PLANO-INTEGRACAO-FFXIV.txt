# Plano: Integração APIs FFXIV no Hall of the Novice EX
# Data: 29/07/2026

## APIs a serem utilizadas

1. XIVAPI (xivapi.com)
   - Uso: Itens, receitas crafting, quests, dungeons, personagens
   - Autenticação: Chave de API (gratuita via Discord)
   - Documentação: https://v2.xivapi.com/docs/welcome/

2. Universalis (universalis.app)
   - Uso: Preços de market board
   - Autenticação: Nenhuma
   - Endpoint: https://universalis.app/api/v2/{world}/{itemIds}

3. ConsoleGamesWiki API MediaWiki
   - Uso: Dados complementares de wiki
   - Autenticação: Nenhuma
   - Endpoint: https://ffxiv.consolegameswiki.com/mediawiki/api.php

---

## Arquitetura

Frontend (React) → Backend (Express) → APIs Externas
                      ↓
                  Cache em memória (TTL 30min)
                      ↓
                  Supabase (opcional: persistência)

## Etapas de implementação

### Etapa 1: Backend - Serviço de APIs FFXIV
Arquivo: src/lib/ffxiv-api.ts (novo)

- Criar cliente HTTP para XIVAPI, Universalis e MediaWiki
- Sistema de cache em memória com TTL configurável
- Tratamento de erros e rate limiting

Funcionalidades:
- fetchFromXIVAPI(endpoint, params) - Busca genérica na XIVAPI
- fetchFromUniversalis(world, itemIds) - Busca preços market
- fetchFromWiki(action, params) - Busca na wiki MediaWiki
- Cache com TTL de 30 minutos por padrão
- Retry automático em caso de falha

### Etapa 2: Backend - Endpoints internos
Arquivo: server.js (adicionar novas rotas)

Rotas a adicionar:
- GET /api/ffxiv/items?search=         → Buscar itens

- Rotas públicas (somente leitura)

## Configuração necessária

### Variável de ambiente (adicionar ao .env):
XIVAPI_KEY=sua_chave_aqui

### Como obter a chave XIVAPI:
1. Acesse https://xivapi.com
2. Clique em "Login via Discord"
3. Autorize o aplicativo
4. Acesse "Manage Account"
5. Clique em "Generate API Key"
6. Copie a chave e adicione ao arquivo .env

Nota: A API permite algumas consultas sem chave, mas com limite de taxa.
Com chave: 250 requisições/minuto. Sem chave: 5 requisições/minuto.
