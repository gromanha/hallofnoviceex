================================================================================
PLANO: Seção de Receitas FFXIV — Hall of the Novice EX
================================================================================

Resumo: Criar uma seção completa de receitas do cookbook oficial de Final Fantasy
XIV, integrada ao site existente, com tabela separada no Supabase, CRUD via API,
painel admin com editor por seções, e página de leitura fiel ao cookbook.

================================================================================
1. BANCO DE DADOS — Schema SQL
================================================================================

Tabela recipes:
  - id (UUID PK)
  - slug (TEXT UNIQUE)
  - title (TEXT NOT NULL)
  - category (TEXT) → breakfast|appetizers|breads|soups_stews|main_dishes|sides|desserts|drinks
  - regional_cuisine (TEXT) → ex: "Yok Tural", "La Noscea"
  - description (TEXT) → lore/descrição narrativa
  - lore_quotes (JSONB) → [{speaker, text, icon}]
  - difficulty (TEXT) → Easy|Medium|Hard
  - prep_time (TEXT)
  - inactive_time (TEXT)
  - cook_time (TEXT)
  - yield_text (TEXT) → ex: "6 servings"
  - dietary_notes (TEXT)
  - equipment (TEXT)
  - ingredient_sections (JSONB) → [{section_name, items: [{quantity, unit, name}]}]
  - instruction_sections (JSONB) → [{section_name, steps: [string]}]
  - cover_image (TEXT)
  - status (TEXT) → published|draft
  - created_by (UUID FK → admins)
  - created_at (TIMESTAMPTZ)
  - updated_at (TIMESTAMPTZ)

Tabela recipe_categories:
  - id (UUID PK)
  - key (TEXT UNIQUE) → breakfast, appetizers, etc.
  - label (TEXT) → Café da manhã, Aperitivos, etc.
  - icon (TEXT) → UtensilsCrossed
  - sort_order (INTEGER)
  - created_at (TIMESTAMPTZ)

RLS Policies:
  - Leitura pública: status = 'published'
  - Leitura pública para recipe_categories
  - Admin pode CRUD completo

================================================================================
2. API REST — server.js
================================================================================

Endpoints:

  GET    /api/recipes              Listagem pública (filtros: category, search, status)
  GET    /api/recipes?slug=xxx     Busca por slug
  POST   /api/recipes              Criar receita (admin only)
  PATCH  /api/recipes              Editar receita (admin only)
  DELETE /api/recipes              Excluir receita (admin only)

  GET    /api/recipe-categories    Listar categorias (público)
  POST   /api/recipe-categories    Criar categoria (admin)
  PATCH  /api/recipe-categories    Editar categoria (admin)
  DELETE /api/recipe-categories    Excluir categoria (admin)

Validações:
  - category deve ser snake_case válido
  - difficulty deve ser Easy|Medium|Hard
  - ingredient_sections e instruction_sections são JSON arrays
  - Slug gerado automaticamente do título (com dedup)
