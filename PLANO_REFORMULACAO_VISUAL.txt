  1. VISÃO GERAL DO PROJETO
═══════════════════════════════════════════════════════════════════════════════

  O site "Hall of the Novice EX [HoN]" é a plataforma digital de uma Free
  Company brasileira de Final Fantasy XIV, projetada como uma "Academia de
  Magia, Batalha e Artesanato" inspirada em Old Sharlayan.

  O usuário deseja refazer O VISUAL do site do zero, mantendo a estrutura
  funcional existente. O visual deve seguir:

  1. ESTRUTURA similar ao site de referência (site.jpg — PixelVault)
  2. VISUAL da academia (imagens da pasta identidade/)
  3. IMERSÃO total — sensação de caminhar pelo campus da escola de magia
  4. IMAGENS AI-GENERATED para decoração e imersão

  Stack técnico: React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion
  Backend: Express.js + Supabase
  Deploy: Vercel

  3. DIREÇÃO VISUAL: "THE MAGICAL CAMPUS"
═══════════════════════════════════════════════════════════════════════════════

  Tese: O visitante está dentro do campus da Majestic Battle Academy. Cada
  seção do site é um "cômodo" ou "área" da escola de magia. A navegação é
  caminhar pelo campus — do saguão iluminado para a biblioteca, dos jardins
  para a sala de aula.

  A interface desaparece; a experiência é imersiva, acolhedora e viva.

  Características-chave:
  - Ground cream quente (#F5EFE0) — iluminado, acolhedor, não frio
  - Academy Teal (#5BA4B5) como cor de ação principal
  - Academy Gold (#C9A84C) como cor de identidade
  - Academy Lavender (#9B7EC8) para highlights terciários
  - Academy Sage (#7BA68A) para elementos naturais
  - Cards com textura de parchment e bordas douradas sutil
  - Cormorant Garamond para corpo, Cinzel para heading cerimonial
  - Espaçamento generoso com layout de campus
  - Motion: livros flutuando, cristais brilhando, hera balançando

  Estilo de referência:
  - Studio Ghibli (Ilha dos Gatos, O Castelo Animado)
  - Final Fantasy XIV — Old Sharlayan
  - Makoto Shinkai (Your Name, Weathering with You)
  - Arte conceitual de RPG acadêmico

  14. RISCOS E CONSIDERAÇÕES
═══════════════════════════════════════════════════════════════════════════════

  1. PERFORMANCE
     Risco: Imagens AI grandes podem deixar o site lento
     Mitigação: WebP compression (qualidade 85%), lazy loading,
     blur placeholders (20x20px, 20px blur), responsive images

  2. CONSISTÊNCIA
     Risco: Manter paleta consistente em 9 páginas + 40 componentes
     Mitigação: Design tokens rigorosos via CSS custom properties,
     documentação clara no DESIGN.md

  3. DARK MODE
     Risco: O campus à noite precisa funcionar visualmente
     Mitigação: Paleta separada com tons azulados, cristais mais
     brilhantes, testar em todos os componentes

  4. MOBILE
     Risco: Sidebar em mobile precisa de redesign completo
     Mitigação: Bottom navigation bar (como site.jpg), hamburger
     overlay, testar em dispositivos reais

  5. ADMIN
     Risco: O admin pode perder usabilidade com visual decorativo
     Mitigação: Manter admin mais funcional, usar academy colors
     apenas em headers e badges, priorizar usabilidade

  6. ACESSIBILIDADE
     Risco: Decoração pode prejudicar contraste e navegação
     Mitigação: WCAG AA contraste, skip links, sr-only labels,
     focus visible, reduced motion

  7. DEPENDÊNCIA DE IMAGENS
     Risco: Site ficar "feio" sem as imagens AI-generated
     Mitigação: Placeholders coloridos, gradientes de fallback,
     gerar imagens antes de implementar componentes
