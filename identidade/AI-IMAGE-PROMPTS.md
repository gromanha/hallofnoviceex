## 🎨 GUIA DE ESTILO PARA GERAÇÃO

### Consistência de Estilo
Todas as imagens devem seguir:
- **Estilo:** Watercolor illustration (não fotorrealista)
- **Referência:** Studio Ghibli, Makoto Shinkai, arte conceitual de Final Fantasy
- **Paleta:** Teal + Gold + Cream + Lavender + Sage
- **Atmosfera:** Warm, acolhedora, mágica, acadêmica
- **Sem texto:** Nenhuma imagem deve conter palavras ou letras

### Configurações Recomendadas
- **Midjourney:** `--style raw --stylize 250 --ar 16:9`
- **DALL-E 3:** `quality: hd, style: natural`
- **Stable Diffusion:** `CFG 7-8, steps 30+, sampler: DPM++ 2M Karras`

### Pós-Processamento
1. Ajustar brilho/contraste para consistência
2. Aplicar slight vignette nas edges
3. Comprimir para WebP (qualidade 85%)
4. Criar blur placeholders (20px blur, 20x20px)
5. Otimizar para lazy loading
